## 방법

1. 검색창에 만들 문서 제목을 입력하고 검색합니다.
2. 결과가 없으면 **문서 만들기** 버튼이 나타납니다. 누르면 GitHub 새 파일 화면이 열립니다.
3. 내용을 쓰고 **Commit changes** 를 누릅니다.
4. 1분 정도 뒤 사이트에 나타납니다.

또는 저장소의 `pages/` 폴더에 `제목.md` 파일을 직접 추가해도 됩니다. 제목에 `/` 를 쓰고 싶으면 하위 폴더로 만드세요. 예: `pages/게임/마인크래프트.md` 는 `게임/마인크래프트` 문서가 됩니다.

문법은 [[문법 도움말]]에서 확인하세요. 돌아가기: [[대문]]
